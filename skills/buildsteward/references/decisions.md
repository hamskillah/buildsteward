# Decisions

Routine: follow existing conventions. Comparative: assess 2–3 alternatives. Architectural: source-backed trade-offs and reversibility. Critical: hard gate, risk challenge, approval where required.

- Hard gates: platform compatibility, permitted license, safety/security constraints, cost and user policy. Unknown ≠ pass.
- Evaluate necessity before picking dependencies. Choose evidence quality over star counts or model familiarity.
- Propose a selected option, WHY it fits, rejected alternatives and remaining uncertainty.
- Stop when a justified choice exists. Reopen only if requirements or material evidence changed.
- If the CLI is available, retrieve one matching Steward Library entry on demand; otherwise use the focused skill references. Never demand a missing repository-level file.
