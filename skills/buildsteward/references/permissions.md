# Autonomy and Approval

**Autonomous:** agent makes in-scope, reversible engineering decisions without routine user approval. Ask a focused question when a missing product choice materially changes direction. Production changes, data deletion, spending, credentials scope, and major mission pivots require explicit scope authorization.

**Approval:** agent must still choose and explain an option itself; group related consequential decisions in an approval package. Once granted, reuse only within its recorded scope and time. Minor edits within approved scope need no new user approval.

Decision authority ≠ execution authority. Host permissions/tool guards must enforce external actions. Do not self-grant approval via accessible CLI or infer user consent from an unchecked file.
