# Product interface engineering

1. Understand user task, information hierarchy, state transitions and devices.
2. Identify existing design system, fonts, tokens and interaction conventions.
3. Define flows and states: normal, loading, empty, error, validation, success and disabled.
4. Implement responsive layout, semantic elements, keyboard/touch interaction and color contrast.
5. Use WCAG 2.2 as criteria when applicable, but do not assume automated checks prove accessibility.
6. Render and inspect actual output if browser/screenshot tools are available; test breakpoints and relevant interactions.
7. If visuals could not be observed, mark visual verification as not performed.

**Do not** replace product style solely to match model aesthetic preferences.
